Tech Stack of my front-end project.
Bundler & Core: Vite 8 + React 19 + TypeScript 6.
Architecture: LFA (Layered Feature Architecture), 3 layers: app, features, shared.
State Managment: Redux Toolkit.
Backend: Node.js + Better-Auth + SQLite (Session via HTTP-Only cookies).
Form validation: React Hook Form + Zod + @hookform/resolvers/zod
Translations: i18next + react-i18next + LanguageDetector.
Code quality: ESLint (eslint.config.js).
